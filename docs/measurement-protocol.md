# 测量协议 checklist

> 规则先于结果（MLPerf）。**任何性能数字在被引用之前必须逐条过这张表。**
>
> 这张表不是从原则上推出来的，是从本项目的实际事故里长出来的：
> 2026-09-12 一轮里出现了四次假结果，每一次都通过了当时"看起来合理"的检查。

---

## 0. 一条元规则

**在证据不足时不要下因果判断 —— 补一个能证伪它的实验，或者把它标成假设。**

本项目七次归因错误（磁盘是代价 / V157 已消掉 / uv 缓存 65% 命中 / 跨盘导致重下 /
fadvise 没生效 / 批量为敌 / 用那个 venv 的只有我），全部是同一个失效模式。
其中一次误杀了同机另一个 agent 的在跑实验。

---

## 1. 注入 / hook 类实验

- [ ] **必须自证触发过。** 记录每次调用的计数，并写进结果 JSON。
      `inject=0` 时所有臂跑的是同一份代码 —— 会产出一份"全臂零开销"的漂亮假结果。
- [ ] 计数要**分点记录**（顶层 forward / 子模块 hook / 层 hook 各一个），
      因为调用路径会在框架版本间变化。本项目的实测：vLLM V1 的 VL 模型
      **顶层 `forward` 收到 `input_ids=None`**（走 `inputs_embeds`），只有
      `embed_tokens` 的 pre-hook 有效。
- [ ] 引擎若把执行体放在**子进程**（vLLM V1 默认如此），进程内 hook 不会生效。
      需要 `VLLM_ENABLE_V1_MULTIPROCESSING=0`，并**在结果里写明**。

## 2. 冷态

- [ ] 冷必须**自证**：`fadvise(DONTNEED)` 后读若干随机页两次，冷/温比 ≥5×
      或边际 ≥2 µs/read，否则 **VOID**（不是"冷"）。
      `scripts/serve_ple_ab.py --selfcheck-cache` 可直接跑，不需要 GPU。
- [ ] 写明**冷工作集**，不只是表大小。本项目实测：48 GiB 的表，
      batch=1 时每次迭代只触 128 token × 16 行 = 2048 页 ≈ **8 MB** ——
      冷信号会被稀释，读者会低估冷代价。
- [ ] 报告里区分 **payload 字节**与**页流量**（4 KiB 对齐读下两者可差 15×）。

## 3. A/B 设计

- [ ] **首尾各放一次基线**，用两者的差作为**噪声地板**；小于地板的差异不得称为结果。
- [ ] **归因必须用配对臂分离单变量。** 本项目实测：没有
      `shm-keygen`（真实 keygen + /dev/shm）这一臂，就会把 keygen 的代价
      误归给磁盘（RAM 43.0 vs NVMe 43.4，换介质在噪声内无差别）。
- [ ] **逐迭代列出，不要只报中位数。** 冷启动发生在第 0 次迭代时，
      中位数会把它藏起来（本项目 `engram-i` it0=37.5 / it2=45.7，中位 42.8）。
- [ ] 同一进程内换臂，避免多次建引擎引入的配置漂移；换臂顺序要能检测漂移。
- [ ] 每条结论必须写明**它对哪种配置成立**（batch / 引擎 / eager-or-graph / 表完整性）。

## 4. 介质与带宽

- [ ] **不要用小文件测吞吐。** 本项目用 1.7 MB 的索引页比较镜像，
      建连开销占主导，选出了**最慢**的那个（ustc 0.56 MB/s vs aliyun 16.98 MB/s，差 30×），
      代价是 40 分钟安装。
- [ ] 报**持续吞吐**：真实大文件、固定区段、足够长的窗口。

## 5. 文档与结论

- [ ] **实测 / 推算 / 假设** 三者必须在文中可区分。未被标为实测的数字不得引用为事实。
- [ ] 「未测」不等于「通过」。门禁里缺失即 FAIL。
- [ ] 验收条目要么给出**可证伪的子条件清单**，要么写明前置条件；
      不要把一个笼统的 ⏳ 挂在验收表上（README §6.1 的六条子条件即此规则的应用）。
- [ ] 负面结果与被推翻的结论**一并落盘** —— 它们比正结果更贵。

## 6. 共享机器

- [ ] 动手前 `cat /proc/<pid>/cmdline` 确认进程归属。**不确定就不动。**
- [ ] 跑性能测试前确认没有他人的负载（`nvidia-smi --query-compute-apps`）；
      并发负载会污染计时，也会让结论不可复现。
- [ ] 在结果里记录测量时的机器占用状态。
