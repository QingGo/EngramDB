# docs/archive — 历史轮次长文摘要

这些文件是**按轮次写的完整复盘**（计划 / 发现 / 尝试 / 踩坑 / 完成 / 未完成）。
它们被移到这里，是为了让 `docs/` 顶层只留**当前有效**的文档。

## 为什么移，而不是删

它们的价值是**失败留档**：里面记着当时试过什么、为什么不行。
删掉就等于把已经付过学费的教训再买一次（roadmap §29.2 的失速模式）。

## 移到这里的规则（roadmap §29.4 Phase 4 / §36.6）

- **按轮次编号的完整复盘** → 这里。它是「当时发生了什么」，不是「现在该做什么」。
- **仍然有效的结论** → 必须已经**提升**进 `roadmap.md` 的活账（§36.5）
  或 `README.md` §6.1，否则不许移。
- **活文档**（`handoff.md`、`session-log.md`、`session-summary.md`、
  `design.md`、`engram-specs.md`、`measurement-protocol.md` 等）**留在顶层**。
